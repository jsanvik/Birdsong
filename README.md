# Understanding Birdsong Network Communication through Machine Learning Algorithms
This project will explore the applicability of Machine Learning and other analyses as a tool to understand network communication of Adelaide’s Warblers.

## Running the Code
Project code is primarily Jupyter Notebooks using the R kernel. If you don't have Jupyter or R set up on your machine, you can run the Jupyter Notebooks (.ipynb files) using [Syzygy](https://uleth.syzygy.ca/). Upload the notebook file you wish to run, and the data to a folder called "data" in the same directory as the notebook.
